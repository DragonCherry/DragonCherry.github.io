콩빌런 analytics

콩빌런 채널이 자기 채널 통계를 읽는 내부 도구 / An internal tool that reads the 콩빌런 channel's own statistics.

무엇을 하나요

콩빌런 유튜브 채널 운영자가 Google 계정으로 직접 승인하면, YouTube Analytics API와 YouTube Data API를 읽기 전용으로 호출해 우리 채널 영상의 조회수, 평균 시청 비율, 구독 증가, 유입 경로를 가져옵니다. 이 숫자는 다음 콘텐츠를 어떻게 만들지 정하는 데만 씁니다.

이 도구는 공개 서비스가 아니며, 다른 사람의 계정이나 채널에는 접근하지 않습니다.

What it does

After the channel owner signs in with Google and grants access, the tool calls the YouTube Analytics API and the YouTube Data API in read-only mode to fetch views, average view percentage, subscribers gained and traffic sources for the 콩빌런 channel's own videos. The numbers are used only to plan the channel's next videos. It is not a public service and never accesses other people's accounts or channels.
