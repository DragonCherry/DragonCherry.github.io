개인정보처리방침 · Privacy Policy

콩빌런 analytics · 시행일 2026-11-26 · Effective 2026-11-26

1. 수집하는 정보

채널 운영자가 Google 로그인으로 승인한 경우에만, 콩빌런 유튜브 채널의 통계(영상별 조회수, 시청 시간·평균 시청 비율, 구독 증가, 좋아요·공유 수, 유입 경로)와 채널·영상 기본 정보를 YouTube API로 읽습니다. 시청자 개인을 식별하는 정보는 받지 않으며, API가 집계해서 주는 숫자만 다룹니다.

2. 이용 목적

어떤 콘텐츠가 잘 보였는지 분석해 다음 콘텐츠를 기획하는 데만 사용합니다. 광고, 판매, 제3자 제공에 사용하지 않습니다.

3. 보관과 보안

인증 토큰은 채널 운영자의 컴퓨터에 있는 암호화된 저장소에만 보관하고, 통계 숫자는 같은 컴퓨터의 작업 파일에 저장합니다. 외부 서버로 보내지 않습니다.

4. 제3자 제공

수집한 정보를 제3자에게 팔거나 넘기지 않습니다. Google API 서비스에서 받은 정보의 사용과 전송은 Google API Services User Data Policy의 Limited Use 요건을 따릅니다.

5. 권한 철회와 삭제

언제든지 Google 계정 권한 설정에서 "콩빌런 analytics" 접근을 철회할 수 있습니다. 철회하거나 요청하면 보관 중인 토큰과 통계 파일을 삭제합니다.

English summary

With the channel owner's Google consent, 콩빌런 analytics reads aggregated YouTube Analytics and YouTube Data statistics for the 콩빌런 channel only (views, watch time, average view percentage, subscribers gained, likes, shares, traffic sources). No personal data about viewers is collected. Data is used only to plan the channel's content, is stored only on the owner's own computer (tokens in an encrypted store), is never sold or shared, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions; on revocation or request, stored tokens and data are deleted.
